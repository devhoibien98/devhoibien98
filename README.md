# ☁️ DevOps & Cloud

Mình đang phát triển từ **Fullstack Developer** thành developer có thể đảm nhiệm toàn bộ vòng đời của một hệ thống:

### **Build → Test → Ship → Deploy → Operate → Scale**

Đang tập trung phát triển:

* **Linux** — server, process, networking và system administration
* **Docker** — containerization, images, networking và production containers
* **CI/CD** — tự động hóa build, test và deployment
* **Kubernetes** — orchestration, scaling, service discovery và deployment
* **Helm** — quản lý Kubernetes applications
* **Terraform** — Infrastructure as Code
* **AWS** — cloud infrastructure và deployment
* **Nginx** — reverse proxy và load balancing
* **Observability** — logging, metrics, monitoring và alerting
* **Security** — secrets, IAM, network security và secure deployment
